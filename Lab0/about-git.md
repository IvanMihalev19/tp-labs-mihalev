# About Git

1. Чем ветка отличается от копии папки с проектом?

Ветка в Git — это не физическая копия файлов, а просто ссылка на определённый коммит в истории проекта.

2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?

Если удалить все файлы проекта, кроме папки .git, то история коммитов, все ветки и теги сохранятся в целости.

3. Зачем нужен Pull Request, если можно коммитить сразу в main?

Pull Request — это не просто способ внести изменения, а механизм для командной работы и контроля качества кода. Он позволяет другим разработчикам просмотреть изменения, обсудить их, предложить улучшения и проверить код на ошибки до того, как он попадёт в основную ветку.
